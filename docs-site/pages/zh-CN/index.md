# wok-ui-ext 组件库

wok-ui-ext 是基于 **wok-ui** 的主题扩展组件库，提供一整套科技蓝风格的企业后台组件。

## 特性

- **科技蓝主题** — 统一的设计语言，基于 CSS 自定义属性体系
- **高频组件** — 专注企业后台实际使用频率高的组件，不做大而全
- **多主题支持** — 内置深邃夜空、活力橙、神秘紫、森林绿、烈焰红 5 套主题
- **国际化** — 内置中英文支持，可扩展

## 快速开始

浏览左侧菜单查看各组件的文档和使用示例。
