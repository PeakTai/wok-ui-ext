# wok-ui-ext Components

wok-ui-ext is a theme extension library based on **wok-ui**, providing a collection of tech-blue styled enterprise-grade components for admin systems.

## Features

- **Tech-blue theme** — Unified design language with CSS custom properties
- **High-frequency components** — Focus on real-world admin panel usage, not feature-bloated
- **Theme support** — Multiple built-in themes: Night Sky, Orange, Purple, Green, Red
- **i18n ready** — Built-in Chinese and English support
